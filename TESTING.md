# Testing and build acceptance

## Required CI checks

```sh
cd app
npm ci
npm run build:verify
npm run i18n:check
npm test
cd ..
node scripts/check-app-security.cjs
node scripts/check-test-policy.cjs
cargo clippy --manifest-path app/src-tauri/Cargo.toml --locked --all-targets -- -D warnings
```

The Playwright suite exercises UI journeys with native Tauri commands simulated; it does not replace Telegram service tests, OS key-store validation, packaged desktop smoke tests, or Android acceptance. CI separately builds the Windows, macOS, and Linux bundles, creates an unsigned Android debug APK, installs it on an Android emulator, launches the app, checks the initial authentication/onboarding UI, and scans logcat for fatal/JNI errors. Artifact uploads contain build outputs only; there are no release publishing, deployment, production signing, or payment-service steps.

## Android build

The Android Gradle project is generated by Tauri and deliberately excluded from source control. CI runs `npm run tauri -- android init`, applies the local `scripts/prepare-android-ci.cjs` bridge to that generated project, and builds a debug APK. The helper stores Telegram API hashes with AES-GCM using an Android Keystore key. No signing key or production credential is required for this debug artifact.

Do not mark an Android install/launch/logcat check as passed unless emulator/device evidence from the actual run is available. The emulator is a smoke test, not a substitute for acceptance on physical Android phones and Android TV.
