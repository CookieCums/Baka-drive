# Changelog

## 0.1.0 — Baka Drive fork baseline

- Started a separate Baka Drive application identity based on the Telegram Drive source project.
- Removed advertising placements, payment/supporter activation, donation prompts, crash-report transport, and upstream auto-update endpoints.
- Preserved Telegram authentication, file management, media playback, local REST/WebDAV access, transfer flows, and optional encryption.
- Added CI-only cross-platform packaging and Android debug-artifact workflow configuration.
- Clarified local data handling, security boundaries, and licensing limitations.

> This fork has not added or changed a source license. Redistribution rights remain unresolved; keep the repository private until an appropriate license is confirmed by the rightsholder.
